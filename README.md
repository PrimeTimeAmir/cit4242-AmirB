# CIT4242 — Advanced Programming

This repository contains my work for the CIT4242 Advanced Programming course at KIMEP University.

During the semester, I will develop and extend a Java-based project while practicing advanced programming concepts, object-oriented programming, testing, Git, Maven, and software development practices.

The project will gradually grow throughout the semester. I will use Maven to manage the project and its build lifecycle, Git and GitHub for version control, and Java 21 as the main programming language.

The main goal of this repository is to build a well-structured Java project and improve my practical programming and software development skills through weekly assignments and exercises.

## Technologies

- Java 21
- Maven
- Git
- GitHub
- IntelliJ IDEA
